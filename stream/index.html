Eine Quelle für alle Rechner: In OBS nur diese Adressen eintragen, keine Dateien kopieren. Änderungen kommen von selbst an.

  1. OBS: Quellen → „+“ → Browser. Haken „Lokale Datei“ aus.
  2. Adresse von hier ins Feld URL kopieren, Breite 1920, Höhe 1080.
  3. Zeigt OBS noch eine alte Fassung: Eigenschaften der Quelle → „Cache der aktuellen Seite aktualisieren“.
